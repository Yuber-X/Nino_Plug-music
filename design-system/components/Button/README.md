Tres variantes: primario (superficie `wine-700`, para una sola acción destacada por vista), secundario (contorno `line-strong`, transparente) y fantasma (solo texto `ash-300`, para acciones terciarias como "Contacto"). Todos en `mono`/`label`, mayúsculas, `radius-none`.

**El consumidor provee:** el texto del botón (verbo + objeto corto, nunca "Click aquí") y el destino.

**Uso:**
- Máximo un botón `primary` visible a la vez por sección — es el acento `wine-700`, y repetirlo le quita jerarquía.
- El botón fantasma no lleva borde ni fondo: se apoya solo en el color de texto y, opcionalmente, una flecha.

**No hacer:** botones con esquinas redondeadas o sombra — rompe la firma de filo recto del sistema.
